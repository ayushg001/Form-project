# 🎓 Student Registration & Form PDF Portal

A minimal, client-side web application for filling official college forms, viewing real-time printable A4 replicas, and downloading PDFs directly in the browser.

## 🚀 Quick Start

### 1. Run Locally
```bash
npm run dev
```

### 2. Build for Production
```bash
npm run build
```

## 📄 Available Forms
1. **ID Card Cum Library Card**
2. **UG Course Registration (3rd Year)**
3. **Academic Session Registration Form**

*Runs 100% in-browser with zero database or cloud service dependencies.*
